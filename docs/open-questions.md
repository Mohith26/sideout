# Open questions

Questions the build spec ([`build-spec.md`](./build-spec.md) §17) marks **OPEN**. None of
these are guessed at in code. Each one has a documented fallback that is implemented,
marked at the point of use with an `// OPEN:` comment, and listed here with the phase that
owns it. Later phases append to this file rather than resolving anything silently.

| **A finished attempt and later writes.** The docs say a score "will continue to overwrite the prior score ... unless `attemptFinished=true` was passed, the tournament is closed ... or the user has paid for another attempt", and that `attemptFinished: true` "prevents further score updates for this attempt" — but not whether such a write is reported in `failedMatchupIds` or silently kept.
